# Quickstart: Distributed Bayesian Optimization and Decentralized Scheduling

1. Run `.venv/bin/pytest tests/unit/test_decentralized_bayes.py tests/contract/test_decentralized_bayes_api.py`
2. Run `.venv/bin/pytest`

Expected result: Ada stays one point with setting 1 after a repeated name. A repeated report name does not change the score. After north reports ada with score 2 and south reports ada with score 1, the agreement is mina on north with 2 suggestions. The page shows `Agreement: mina on north, 2 suggestions`. `GET /api/tasks` stays a list of tasks.
