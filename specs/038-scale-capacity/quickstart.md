# Quickstart: Autoscaling and Queue-Based Capacity Planning

From the repository root:

```bash
.venv/bin/pytest tests/unit/test_scale_capacity.py tests/contract/test_scale_capacity_api.py
.venv/bin/pytest
```

The first command covers a capacity plan, a fill, a scale-up, a release, a rolled-back scale, and the page. The second command confirms the existing suite stays green.
