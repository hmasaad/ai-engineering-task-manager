# Quickstart: Run One File Read

From the repository root:

```bash
.venv/bin/pytest tests/unit/test_run_file_read.py tests/contract/test_run_file_read_api.py
.venv/bin/pytest
```

The first command covers one named read, a second name, a folder left pending, a rolled-back run, and the page. The second command confirms the existing suite stays green.
